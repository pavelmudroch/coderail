Ask question one at a time.
Provide recommended answer.
Provide brief context of question for clarity.

Validate each answer and mention caveats, conflicts, or possible trade-offs if any, and recommend better alternatives when available.

If a question can be answered by exploring the codebase or other source use <skill>research</skill>.
