# Elicitation

## Goal

Resolve ambiguities, unanswered questions, and consequential design decisions that block further exploration.

## Boundary

- Identify unknowns, conflicting assumptions, missing constraints, and unresolved decisions.
- Classify uncertainties before acting:
  - **Investigate:** Resolve factual and technical questions independently.
  - **Delegate:** Leave routine implementation decisions to implementation.
  - **Ask:** Seek user judgment on intended behavior, priorities, preferences, constraints, and consequential trade-offs.
- Prioritize questions by impact, dependencies, and ability to unblock exploration.
- Resolve foundational decisions before dependent details.
- Ask one focused, high-impact question at a time; group a few closely related questions when useful.
- Avoid overwhelming the user with exhaustive questionnaires or premature implementation details.
- Provide sufficient context to make each decision understandable.
- Recommend a preferred approach with reasoning and meaningful alternatives when appropriate.
- Explain trade-offs and consequences using concrete behavioral scenarios.
- Avoid presenting speculative alternatives without meaningful differences.
- Distinguish confirmed decisions from proposals, assumptions, and unresolved questions.
- Challenge ambiguous or contradictory answers without repeatedly questioning settled decisions.
- Revisit prior decisions only when new information materially affects them.
- Never infer user agreement from silence.

## Completion

- Record confirmed decisions, relevant rationale, and constraints in the appropriate ideas.
- Update affected questions and dependent ideas.
- Preserve unresolved or deferred questions explicitly.
- Resume exploration after resolving or explicitly deferring the current blocking uncertainty.
- Select the next highest-impact uncertainty or exploration activity.
